# Локальные таргеты WowVoice

Этот файл хранится в Git и содержит общие команды без персональных путей.
Открой его в IntelliJ IDEA и запускай нужный блок кнопкой Run рядом с командой.
Рабочая директория запуска — корень твоей копии проекта.
Эти же команды можно выполнять в терминале из корня проекта.

## Настройка путей — один раз на каждом ПК

Скопируй [пример переменных окружения](config/build.env.example.ps1)
в `config/build.env.local.ps1` и замени демонстрационный путь на свой.
Локальный файл исключён из Git; не перезаписывай его при повторной настройке.

В нём задаётся `$env:WOWVOICE_FOREVER_BETA_ADDONS` — полный путь до
`_classic_beta_\Interface\AddOns`. Эта папка должна уже существовать.
`DeployAddon` автоматически загружает локальный файл, поэтому команды
ниже менять не нужно. Переменные действуют только в процессе сборки,
системные настройки Windows не меняются.

Без локального файла используется переменная окружения, заданная при запуске.
Если файл есть, его значения имеют приоритет. Проверка, тесты, упаковка
и статистика не требуют пути к игре. Пути внутри проекта определяются автоматически.

Старый `config/deploy.targets.local.psd1` автоматически больше не читается.
Для явного использования такого конфига остаётся параметр `-ConfigPath`;
при нём локальный файл переменных не загружается.

## Статистика скачиваний и переходов — локальный отчёт

```shell
.\stats.cmd
```

Получает свежие счётчики GitHub и переходы на CurseForge из GoatCounter,
открывает отчёт в браузере. Можно также
запустить `stats.cmd` двойным щелчком в проводнике. Для обновления запусти его снова.
Без открытия браузера: `.\stats.cmd -NoOpen`.

Отчёт: [открыть таблицу](artifacts/stats/index.html),
[CSV для Excel](artifacts/stats/downloads.csv).
Эти файлы остаются только на этом ПК: исключены из Git и находятся вне папки
синхронизации pCloud. Скрипт использует `GITHUB_TOKEN`/`GH_TOKEN`, если они заданы,
иначе — уже сохранённый вход Git в GitHub. Окна входа и запросы пароля не открываются;
токен остаётся в памяти и не записывается в отчёт. Без входа доступен публичный API,
но его лимит — 60 запросов в час на IP. Обычно весь отчёт требует один запрос.
При исчерпании лимита показано время повторного запуска. При сетевом сбое GitHub
выполняются до трёх попыток с тайм-аутом 10 секунд на запрос. Если GitHub недоступен,
отчёт показывает последние сохранённые скачивания с датой и предупреждением;
переходы из GoatCounter обновляются независимо. Если сохранённых скачиваний нет,
показывается «—», а не ноль. Последние успешные `downloads.csv` и `downloads.json`
при сбое GitHub не перезаписываются.

Начиная с 1.2.5 выпускается только архив аддона. Новые сборки называются
`TalkingHeadRu-<версия>.zip`; прежние файлы `*-addon-only.zip` остаются в истории.
В отчёте он обозначен «Аддон», полные архивы прошлых релизов — «Старые полные
архивы». Их скачивания сохраняются в общей сумме; в строках новых выпусков
без полного архива стоит «—». Исторические lite-архивы исключены.
Из `Full`, `AddonOnly` и `Total` вычитаются известные наши проверочные скачивания.
В CSV и JSON остаются прежние имена колонок; число технических проверок не выводится.
Проверки хранятся в [config/release-download-checks.json](config/release-download-checks.json)
по ID файла GitHub: замена архива не переносит вычет на новый файл.
Неизвестные проверки старых релизов не вычитаются.
GitHub учитывает также повторные и проверочные скачивания, без выделения
уникальных пользователей и переходов с сайта. pCloud и скачивания библиотек
с CurseForge не входят в эти числа.
Сами исходные счётчики GitHub публичны; локальный отчёт нигде не публикуется.

Клики по кнопке «Открыть на CurseForge» в баннере CurseForge учитываются отдельно через
[GoatCounter](https://tove2889.goatcounter.com/): событие `curseforge-open`,
название «Переход на CurseForge». Повторные клики тоже учитываются; это не число
установок или уникальных пользователей. Просмотры страниц автоматически не отправляются.
Счётчик включается только в опубликованной сборке на
`https://olegbuchnev.github.io/WowVoiceTalkingHead/`; локальный предпросмотр и
локальные копии сайта не загружают аналитику. Блокировка счётчика не мешает переходу.
После публикации проверить событие реальным кликом и его появлением в GoatCounter.

Для чтения переходов через `stats.cmd` создайте токен в GoatCounter:
имя пользователя справа вверху → **API**, с правом чтения статистики.
Сохраните только токен одной строкой в `config/goatcounter-token.local.txt`
(файл исключён из Git). Альтернатива — переменная окружения
`GOATCOUNTER_API_TOKEN`; она имеет приоритет. Токен не нужен в коде сайта,
архиве аддона или GitHub Actions и не записывается в отчёт.

В отчёте есть отдельный блок «Переходы на CurseForge с сайта» за период
с 10.10.2026 и файлы `artifacts/stats/curseforge-clicks.csv` и
`artifacts/stats/curseforge-clicks.json`. Скачивания ZIP и клики не суммируются.
Если токен не настроен, показывается «не подключено»; при ошибке API сохраняется
предыдущий результат с пометкой и временем его получения, а не ложный ноль.

Наши клики исключаем в браузере после публикации счётчика: откройте
`https://olegbuchnev.github.io/WowVoiceTalkingHead/#toggle-goatcounter`,
дождитесь уведомления **DISABLED**, затем вернитесь на URL без этого фрагмента.
Повторное открытие ссылки включает подсчёт обратно. Исключение действует
для текущего профиля браузера, пока не очищены данные сайта.
Если проверочные клики уже попали в GoatCounter, добавьте их в `checks` файла
`config/curseforge-click-checks.json`, например:
`{"count": 1, "note": "Проверочный переход после публикации"}`.
Записывайте только действительно учтённые клики: уже заблокированные браузером
и локальные клики повторно вычитать нельзя. Автоматически распознать автора
среди уже собранных кликов невозможно. Известные проверки вычитаются из общего
числа без ухода в минус; исходное число и вычет сохраняются в локальном JSON.

Папка `artifacts/WoWVoice`, опубликованные архивы и установленные аддоны не меняются.
После правок только текста или оформления достаточно `node tools/build-site.mjs --preview`.
Локальные примеры открывай в Firefox. Проверяй раскрытие «Что нового» также
в невысоком окне: левый столбец закрепляется только когда целиком помещается
по высоте и не должен прыгать при раскрытии или сворачивании выпуска.
Раскрытие и сворачивание описания занимают 260 мс; при системном уменьшении
анимации переключение мгновенное. Проверь также быстрые повторные нажатия,
Enter/пробел и переход между выпусками: предыдущий плавно закрывается.
Прокрутка синхронна с изменением высоты: описание должно целиком попадать
в окно, если помещается по высоте; у длинного описания показывается начало.
Прокрутка колесом или касание экрана отменяет автоматическую прокрутку.
Если меняется содержимое аддона в архиве, запусти полную команду ещё раз.
Раздел «Что нового» берётся из README: один свёрнутый блок `<details name="releases">`
на выпуск, новые выпуски сверху. Общее имя группы позволяет открывать только один
выпуск одновременно. Перед публикацией замени «Следующее обновление · готовится
к выпуску» в `<summary>` на номер версии и фактическую дату, например
«Версия X.Y.Z · 2 октября 2026». Прошлые записи сохраняй с их исходными датами.
Имена картинок, CSS и JavaScript на сайте автоматически содержат SHA-256 их содержимого.
При обновлении страницы браузер получает соответствующие ей стили и скрипт,
даже если прежние файлы ещё находятся в кэше. Проверяй также повторный заход
после публикации, а не только открытие сайта в чистом профиле браузера.
При замене скриншота его адрес меняется и обновлённая страница загружает новую
картинку; вручную переименовывать файл в `docs/images/` не нужно.

## Test — запустить тесты

```shell
.\build.cmd -Task Test
```

Английский клиент (enUS/enGB): переведены плеер и подписи головы; настройки и
каталог озвучки остаются на русском. Голова наследует `QuestFont`/`QuestTitleFont`;
для кириллицы выбираются штатные варианты Blizzard `FRIZQT___CYR`/`MORPHEUS_CYR`,
для английского текста возвращается исходный шрифт. Внешний Noto Sans удалён.
«Вспомнить задание» остаётся на русском во всех клиентах: `/thead remindertest`
на enUS/enGB должен показывать буквы без квадратов, включая повторный показ.
После `/reload` проверь русские имена/тексты головы, очереди и настроек, затем
английское задание. Сравни шрифты тела/заголовка с окном задания Blizzard:
квадратов быть не должно, кнопки плеера остаются английскими, звук и автопереход — прежними.
Приоритет текста: ruRU — текст задания/журнала из игры; enUS/enGB — русская запись
из `QuestTexts.lua`, при её отсутствии — игровой текст. Это действует для обеих
озвучек и без звуковых пакетов. Проверь также `/reload` с очередью: оригинальный
игровой текст сохраняется, а язык для показа выбирается заново при проигрывании.

## DeployAddon — обновить только аддон в локальном Forever Beta

```shell
.\build.cmd -Task DeployAddon -Target ForeverBeta
```

Обновляет `TalkingHeadRu` из `src/`, с резервной копией в `backups/`.
Если осталась старая папка `WowVoiceTalkingHead`, сохраняет её в резервную копию
и удаляет из `AddOns`. Файлы настроек в `WTF` не изменяются.
Звуковая база в `WowVoiceSounds` не обновляется и не копируется
в резервную копию. Локальные исходники звуков для этого таргета не нужны.
При первом переходе на папку `TalkingHeadRu` полностью перезапусти игру.
Для дальнейших обновлений существующих файлов достаточно `/reload`.

CatQuest: кнопка «Читать» скрывается также в приветствии NPC (`GossipFrame`),
перед выбором задания, на всех языках клиента. Проверь повторное открытие диалога
и `/reload`; кнопка чтения книг остаётся доступной. `/thead off` восстанавливает
исходную видимость кнопок CatQuest.

Проверка модели после `/reload` во время озвучки: восстановленная реплика должна
начинаться с нуля после закрытия экрана загрузки, получать полную длительность
заново и показывать движущуюся голову, включая повтор разговорной анимации.
Проверь `/reload` в середине длинной записи и выход с возвращением менее чем
через 5 минут: запись должна доиграть целиком, затем очередь продолжается.
Время до перезагрузки и время загрузки не сокращают реплику; выключенное
автовоспроизведение сохраняется. Обычное сворачивание игры не перезапускает трек.
Звук и прогресс головы используют общий точный таймер, чтобы долгий первый кадр
после загрузки не сокращал запись. Если обрыв повторится, включи `/thead debug on`
перед `/reload` и сохрани сообщения запуска и остановки; после проверки —
`/thead debug off`. Эти команды доступны только в локальной сборке.
Если модель снова застынет, `/thead diag` выводит также `Animation` (выбранная анимация,
наличие разговорной, пауза и отложенный запуск). Верхние кнопки плеера распределяют
свободное место между собой поровну при русских и английских подписях.

Проверка одиночной записи после ручного воспроизведения: запусти трек из истории,
открой другое задание у NPC, дождись конца первого трека и только затем прими
задание. Описание должно запуститься без краткого появления плейлиста.
Полоса прогресса новой головы должна начинаться пустой, без вспышки заполненной
полосы от предыдущей реплики. Лог от 04.10.2026 подтвердил: у второй головы
значение уже 0.00005, но текстура штатного StatusBar при показе ещё имеет полную
ширину 542 пикселя. Скрытие только при нуле не помогло: подготовка головы занимает
ненулевое время. Полоса заменена обычной текстурой с явной установкой ширины
перед показом, без задержек по времени или FPS. Проверка в игре от 04.10.2026
подтвердила исправление: при показе второй головы заполнение уже соответствует
новому прогрессу, визуальной вспышки нет. Временная диагностика удалена.
Повтори во время затухания головы и после её исчезновения, с фоновым звуком
и без него. Реальная ожидающая запись при остановленной очереди остаётся доступна.

Внизу основных настроек `/thead` пункт «Если доступны обе озвучки» выбирает
WowVoice (по умолчанию) или CatQuest для общих записей. Выбор сохраняется и действует
для автозапуска, журнала и трекера. Записи, доступные только в одной библиотеке,
используются автоматически. Без совместимого CatQuest Voices пункт неактивен,
причина показана в подсказке. Текущая реплика при изменении выбора не прерывается.
Кнопки в каталоге озвучки всегда запускают явно указанный источник.
Изменение масштаба ползунком или числом показывает предпросмотр головы без тестового
свечения кнопок квестов в обычном трекере и Questie. Общий чекбокс
«Заблокировать фреймы» вверху настроек управляет перемещением головы и очереди:
снимите галочку для редактирования, поставьте для фиксации. Закрытие настроек
также закрепляет оба окна, сохраняя положение и текущую озвучку.
Изменение масштаба очереди показывает только очередь без разблокировки. После
завершения изменения предпросмотр держится две секунды и плавно исчезает.
Изменение масштаба головы по-прежнему показывает только голову.

В трекере Questie кнопка ▶ располагается непосредственно перед названием задания.
Если показана кнопка сворачивания, ▶ стоит левее неё; скрытая кнопка не оставляет
пустого места перед названием. Если строка показывает квестовый предмет, ▶ сдвигается левее
предметов. Затухание предмета при наведении не меняет положение ▶; скрытие
предметов возвращает её обратно. Области нажатия предметов остаются штатными.

Каталог озвучки доступен всем пользователям. Открой `/thead` и нажми
«Послушать озвучку» внизу раздела «Выбор озвучки». Каталог открывается внутри
страницы параметров. Кнопка «Назад» возвращает основные настройки.
Подсказка о выборе источника появляется только на значке «i» рядом с заголовком раздела.
Справа от поля ID показан диапазон из текущего индекса; внутри диапазона есть пропуски.
Поле ID принимает только цифры, максимум 5 символов.
Стандартный крестик очистки поиска внутри поля справа очищает только фильтр
и возвращает фокус для ввода. Он появляется при заполнении поля, подсвечивается
при наведении и скрывается после очистки (как в поиске Details).
Под списком показано число квестов с озвученным вступлением в каждой базе и
общее число уникальных; эти числа не зависят от фильтра. В легенде только WowVoice и CatQuest.
Кнопка «Назад» и закрытие окна настроек сбрасывают фильтр и выделение;
при возвращении показан полный список с начала. Воспроизведение продолжается.
Поле ID оформлено как поля координат. Список занимает всю полезную область под полем,
показывает совпадения по началу ID по возрастанию в 8–12 колонках. Все найденные
ID доступны через прокрутку колёсиком или полосой прокрутки; ограничения первыми
восемью больше нет. В списке только квесты с известным озвученным вступлением;
задания только со сдачей или промежуточной репликой исключены. При пустом поле показаны
все такие квесты. Потеря фокуса не скрывает список.
Каждый ID показан плиткой с двумя кнопками воспроизведения: голубая — WowVoice,
оранжевая — CatQuest. Легенда находится над списком. Если записи у источника нет,
соответствующая сторона плитки пустая. Если запись известна, но недоступна
(например, библиотека отключена), кнопка неактивная: приглушённый цвет источника
и крестик по центру, концами до окружности значка. Всплывающие подсказки не используются.
Нажатие на кнопку сразу запускает выбранную запись с нашей говорящей головой;
соседняя кнопка переключает озвучку того же квеста с начала. Яркой заливкой выделена
только нажатая кнопка воспроизведения; «Назад» снимает выделение.
Для сравнения с CatQuest нужен установленный и включённый CatQuest_Voices.
Метаданные полностью проверены для Voices 0.5.0 и CatQuest 0.5.0.
Без загруженного CatQuest Voices каталог берёт известные описания из нашей базы
`CatQuestAudio.lua`: его кнопки, легенда, квесты и счётчик остаются видимыми.
Это работает и при отключении обеих библиотек. Счётчики отражают известные записи,
а не доступные сейчас. Над сеткой у недоступного источника видна подпись «недоступна».
При загрузке CatQuest используется актуальный индекс библиотеки, кнопки доступных
записей включаются автоматически. Неизвестная источнику запись оставляет пустой слот.
Текст фильтра, результаты и прокрутка сохраняются; фильтр редактируется вручную.
Escape снимает фокус с поля; список остаётся виден. Запуск озвучки также его не скрывает.
Команда `/wvvoices 179` сразу подставляет ID квеста. Кнопки плитки или Enter в поле запускают описание
с портретом без взятия квеста, если запись есть в установленном аудиопаке.
Enter предпочитает WowVoice, затем CatQuest. Прослушивание в каталоге не меняет
обычный выбор источника и не продлевает паузу напоминаний о квесте.
Для WowVoice текст берётся из сохранённого описания или журнала. Если его нет, используется
`src/QuestTexts.lua` — полная база субтитров квестов CatQuest, включая квесты
основной библиотеки WowVoice. Она входит в оба комплекта и не зависит от
установки CatQuest или выбора аудиопака. Учитываются варианты по полу персонажа.
Для CatQuest текст берётся из актуальных субтитров установленной библиотеки.
В непроверенном режиме старые тексты нашего снимка к её записям не подставляются.
Резервные данные NPC находятся в `src/CatQuestSpeakers.lua`: полный снимок
CatQuest/NpcData.lua, включая связи выдающих и принимающих NPC. Для описаний
используется выдающий NPC, если его нет в существующих индексах и сохранениях.
Если в исходнике нет
субтитров, остаётся сообщение «Текст задания недоступен». Портрет зависит от
доступных данных NPC. Кнопки остановки, напоминаний, предпросмотра,
логов и диагностики со страницы удалены. Крестик головы завершает текущую реплику;
при включённом автовоспроизведении очередь переходит к следующей.

Код каталога хранится в `src/VoiceComparison.lua`, выбор записи для прослушивания —
в `src/Comparison.lua`. Оба входят в полную и addon-only сборки. Каталог использует
актуальный индекс установленного CatQuest Voices; `src/CatQuestAudio.lua` даёт точные
длительности проверенных файлов. Старый флаг `-LocalDebug` оставлен для совместимости
команд деплоя и больше не меняет состав аддона. Основная команда каталога — `/wvvoices`;
старый `/wvdebug` доступен как алиас только с локальным QueueLab.

## QueueLab — стенд игровых диалогов только для беты

```shell
.\build.cmd -Task DeployAddon -Target ForeverBeta -QueueLab
```

После `/reload`: `/tt` (также `/thead queuelab`). Окно позволяет
принимать случайные тестовые задания и сдавать их кнопкой в строке.
Стенд вызывает штатные обработчики диалогов и использует общую пользовательскую
очередь для настоящих и тестовых заданий. Ссылка на обработчик берётся из
`WowVoice.eventFrame`, а не из общего имени `WowVoiceFrame`, которое может
принадлежать оригинальному WowVoice. Плеер над чатом группирует записи по NPC.
Своей копии очереди у стенда нет. Настоящий журнал не меняется.
Текст берётся из базы; если его нет, поле остаётся пустым.
`dev/queue-lab/Commands.lua` также подключает локальные команды `/thead`
`remindertest`, `test`, `stoptest`, `diag`, `perf`, `debug`, `source` и алиас `/wvdebug`.
Их обработчики отсутствуют в пользовательских сборках и справке `/thead help`.
Закрытие окна очищает все задания стенда и останавливает его звук.
Кнопка «Очистить» делает то же самое, оставляя окно открытым.

Код хранится в Git в `dev/queue-lab/`, отдельно от релизных исходников.
Чтобы стенд включался при каждом локальном `DeployAddon`, добавь
`$env:WOWVOICE_QUEUE_LAB = '1'` в `config/build.env.local.ps1`.
При отключённой настройке обычный деплой без флага удаляет стенд.
Для разового деплоя без стенда используй `-QueueLab:$false`.
Плейлист включён и в обычных пользовательских архивах.
Галочка «Автовоспроизведение» над списком включает проигрывание подряд.
Если снять её, текущая реплика доиграет, а следующая будет ждать клика.
«Далее» или клик по заданию запускает одну реплику, сохраняя состояние галочки.
Включение галочки продолжает оставшуюся очередь.
Крестик головы (также правый клик по голове) пропускает текущий трек и при
включённом автовоспроизведении запускает следующий. Если галочка заранее снята,
текущий трек останавливается, а остальные ждут клика. Состояние галочки сохраняется.
Автовоспроизведение изначально включено. Выбор через галочку сохраняется для новых
очередей, после `/reload` и перезапуска игры; в опциях дубля галочки нет.
Настоящая очередь сохраняется отдельно для каждого персонажа и восстанавливается после `/reload`
или возвращения в игру менее чем через 5 минут. Прерванная реплика начинается
сначала; очередь с заранее выключенным автовоспроизведением остаётся остановленной.
Пропущенный крестиком трек не возвращается после `/reload`. Во время игры
срока хранения нет. Тестовые задания не сохраняются.
При первом запуске версии с плейлистом все три галки воспроизведения (автозапуск,
получение и сдача заданий) включаются однократно, в том числе после ранней
тестовой сборки с частичной миграцией; последующее отключение сохраняется.
Архивы релиза не содержат стенд и `/tt`; `-QueueLab` при упаковке запрещён.
Подробнее: [правила и устройство стенда](dev/queue-lab/README.md).

## Mock — проверить плашку напоминания

Только при локальном деплое с `-QueueLab` (или `WOWVOICE_QUEUE_LAB=1`).
Мок уведомления о прогрессе в игровом чате после `/reload`:

```text
/thead remindertest
```

Проверка нескольких строк и позднего системного сообщения:

```text
/run WowVoice:TestQuestReminder(); UIErrorsFrame:AddMessage("Первая строка\nВторая строка",1,1,0)
```

Напоминание должно сместиться под видимый текст и оставаться на этой высоте до затухания.

Показывает жёлтый тестовый прогресс и строку «Вспомнить задание» на 5 секунд:
без фона и рамки, сразу под системным текстом, с кнопкой ▶ справа как в трекере.
При наведении строка остаётся видимой; после ухода курсора отсчитываются новые
5 секунд. Случайно выбирается квест из журнала,
чья кнопка озвучки сейчас видна в трекере. Его ▶ подсвечивается на 10 секунд.
Конкретный видимый квест: `/thead remindertest 179`. Убрать строку и тестовую
подсветку: `/thead remindertest off`. Если подходящих квестов нет, появится сообщение в чате.
Тест не меняет прогресс и блокировки, даже после запуска озвучки из тестовой
строки или подсвеченной тестом кнопки в трекере. При реальном прогрессе строка и
подсветка появляются автоматически, без отдельного переключателя, с учётом
паузы после прослушивания описания (включая автозапуск).
Если описание квеста ожидает в плейлисте или проигрывается, реальная строка и
подсветка скрыты, даже при выключенном автовоспроизведении. Проверь прогресс такого
квеста, затем удали его описание из очереди: напоминание возможно только при новом
прогрессе, если нет паузы после прослушивания. Проверь также очередь после `/reload`.
Явный `/thead remindertest` обходит эту проверку, как и остальные условия показа.
Выполнение последней цели, например 8/9 → 9/9, также может вызвать напоминание.
Пауза длится 30 минут; пока она действует, прогресс по этому квесту начинает её заново.
Бой и другие квесты не учитываются. Тестовое прослушивание паузу не включает.

## PackageAddon — собрать релиз аддона

Публикация GitHub Release выполняется через `.github/workflows/release.yml`
при отправке тега `v<версия>-forever`. Workflow проверяет версию всех TOC,
собирает только аддон и берёт описание из соответствующего блока README.
Сначала отправь тег релизного коммита и дождись опубликованного ZIP, затем
отправь этот коммит в `main`: это запускает публикацию сайта с рабочей ссылкой.
Полный `Test` с локальными библиотеками необходимо выполнить до отправки тега.

Техническое имя новой сборки — `TalkingHeadRu`: TOC, папка в AddOns и новые ZIP
используют это имя. `PackageAddon` создаёт
`artifacts/WoWVoice/TalkingHeadRu-<версия>.zip` без суффикса `addon-only`.
В корне архива находится только папка аддона `TalkingHeadRu`.
Инструкция остаётся в репозитории и на странице проекта; `README.txt` в ZIP не добавляется.
Настройки записываются в `TalkingHeadRu.lua` стандартным механизмом WoW.
Переноса прежних настроек и очереди нет: пользователь один раз настраивает аддон
заново. При ручной установке удалить старую папку `WowVoiceTalkingHead` из `AddOns`
и полностью перезапустить игру. DeployAddon удаляет старую папку после резервного
копирования. Опубликованные ранее ссылки и архивы сохраняют прежние имена.

```shell
.\build.cmd -Task PackageAddon
```

Это единственный пользовательский архив: подходит и для первой установки,
и для обновления. WowVoice и CatQuest скачиваются отдельно с CurseForge.

Дополнительная озвучка берётся только из установленного CatQuest_Voices.
Границы задачи согласованы 02.10.2026: отделение логики воспроизведения от
WowVoice и CatQuest выполнено. Зависимость внешнего CatQuest_Voices от CatQuest
принимается как необходимое условие использования пака; устранять её не требуется.
Подхват новых и изменённых записей до уточнения наших метаданных нужен сейчас
только для CatQuest. Текущая база WowVoice использует наш поставляемый индекс;
адаптация к будущей официальной версии WowVoice для Forever будет отдельной задачей,
если такая версия появится. Эти два условия не являются незавершённой частью
текущей задачи.

Решение от 10.10.2026 по CatQuest Codex: ждём выпуска Кодекса, затем проверяем
совместимость при совместном использовании. TalkingHead Ru остаётся легковесным
плеером с ситуативным напоминанием о текущем задании; целевое повторное прослушивание
доступно из журнала заданий. Собственный Кодекс, сюжетные пересказы, карту цепочек,
объединение очередей и перенаправление кнопок CatQuest в наш плеер пока не планируем.
Дальнейшая интеграция рассматривается только при конкретной проблеме совместимости
или подтверждённом пользовательском сценарии. Эта проверка отложена до выпуска
Кодекса и не является незавершённой частью текущего релиза.

Метаданные полностью проверены для Voices 0.5.0 и CatQuest 0.5.0. После обновления
библиотеки новые и изменённые записи работают по её индексу при поддерживаемом формате.
Проверка от 09.10.2026: 3077 квестов, 3017 описаний, 2850 реплик сдачи,
7715 OGG; все файлы проверены по SHA-256 и длительности. По сравнению с Voices
0.4.0 добавлено 951 задание; 4755 файлов с прежними именами изменились.
Тексты: 3017 заданий, 5807 разделов, 7642 варианта; изменены 420 прежних разделов.
Из JSON восстановлены 60 реплик сдачи без описания; для них источник не содержит
субтитров. Все доступные тексты и данные NPC перенесены без расхождений.
Подробности: [миграция CatQuest 0.5.0](docs/internal/catquest-0.5.0-integration.md).
Обновлены собственные тексты, таймеры и база NPC. Интеграция кнопок и подавление
автозапуска CatQuest совместимы с 0.5.0 по установленному коду; после `/reload`
проверь описание и сдачу с выбранным CatQuest, отсутствие двойной озвучки и кнопки «Читать».
До проверки возможна задержка головы и очереди; обновление наших измерений
возвращает точные таймеры каждого OGG.
Поведение согласовано 02.10.2026: несовпадение версий само по себе не отключает
CatQuest. Сохраняется автоматический выбор канала: Master при включённом фоновом
звуке, прежний PlayMusic при выключенном — с заглушением при сворачивании
и продолжением с текущего места при возврате. При приблизительных таймерах
допускаются задержка головы/очереди и возможный повтор начала в PlayMusic.
Настройки музыки игры сохраняются; эксперимент PlaySoundFile на Music не используется
в основном плеере, поскольку он делает слышимой музыку локации.
Уточнение от 03.10.2026: в Music положительная добавка `tail` не применяется
к проверенной длительности OGG (WowVoice и совпадающие записи CatQuest).
Остановка назначается на конец файла; исчезновение головы и пауза очереди
происходят после остановки звука. Master и приблизительные таймеры прежние.
Проверка в клиенте: `/reload`, выключить фоновый звук, `/thead channel auto`,
затем `/run WowVoice:ReplayQuest(1095)`. Проверить окончание описания,
сворачивание/возврат и низкий FPS. Затем повторить с фоновым звуком и Master.
Нулевая добавка не устраняет опоздание до ближайшего кадра. При выборе компромисса
пользователь предпочитает небольшое обрезание окончания короткому повтору начала,
но упреждение под FPS одного клиента не подходит для общего решения и не добавлено.
В подсказке версии в `/thead` для более старого CatQuest Voices рекомендуется
обновить библиотеку до проверенной версии, для более нового — WowVoice TalkingHead.
Старый CatVoices игнорируется; ни DeployAddon, ни Package его не создают.

В комплект также входит основной аддон `WowVoice`. При загрузке нашего аддона
он автоматически отключается в списке модификаций для текущего персонажа;
`WowVoiceSounds` остаётся включённым. `WowVoice` указан в OptionalDeps только
для порядка загрузки: до замены общих глобальных имён отключаются его уже
загруженные обработчики, таймер, кнопка остановки и команды `/wv`, `/wowvoice`.
Его наличие не требуется. Внешние файлы не правим и не удаляем.
Проверка: включить оба плеера, выполнить `/reload`, убедиться, что галочка
`WowVoice` снята, `WowVoiceSounds` включён, а задание озвучивается один раз
с нашей головой. Повторить `/reload` и проверить сохранение выбора и очереди.
Если впоследствии нужен исходный плеер, отключить `TalkingHeadRu`
и включить `WowVoice` вручную.

Если пользователь оставил старую папку `WowVoiceTalkingHead`, новый аддон
автоматически отключает её для текущего персонажа. Если старый аддон уже
загрузился, при входе показывается уведомление с кнопкой перезагрузки интерфейса;
до `/reload` WoW не выгружает его код. Перезагрузка не выполняется без нажатия.
Проверка: включить обе версии, войти, нажать «Перезагрузить интерфейс» и убедиться,
что старый аддон отключён, `/thead` открывает TalkingHead Ru, задание звучит один раз.
Если старая версия уже отключена или отсутствует, уведомление не показывается.

Следующие изменения для перехода на внешнюю установку:

- В настройках «Озвучка WowVoice» берёт `Version` из TOC основного `WowVoice`
  через API метаданных, даже когда он отключён. В проверенной установке это
  `1.0.2`; новые версии отображаются автоматически, без таблицы соответствий.
  Это окончательное решение пользователя от 04.10.2026 вместо сопоставления
  внутренней версии библиотеки `0.1.0` с обозначением `1.60`.
  Без основного WowVoice старая адаптированная сборка сохраняет исходную подпись

  звуков без версии основного аддона — «версия не указана»; озвучка работает.
  Если папки звуков нет, один установленный WowVoice не считается озвучкой.
  Собственные таймеры и проверка доступности озвучки не меняются.
  Проверка в игре: `/reload`, открыть `/thead`; с официальным паком ожидается

- Подготовлен локальный вариант сайта с одной кнопкой «Скачать аддон» и
  одинаково оформленными блоками WowVoice и CatQuest со ссылками на CurseForge.

  аддона; полный архив больше не предлагается. Перед публикацией показать

В старых шаблонах `soundpack/` вложенность WowVoice Sounds задавалась строкой
`## Group: WowVoiceTalkingHead`. Теперь она удалена из обоих TOC: звуковой пак
отображается отдельно. `DeployAddon` не изменяет установленные библиотеки.

Звуковые библиотеки необязательны для загрузки аддона, настроек и каталога.
Общее правило от 02.10.2026: голова и очередь показывают только реплики,
для которых есть запись в подключённой библиотеке. Это заменяет прежний режим
чтения без звука, в том числе при отключении обеих библиотек.
Можно включить только CatQuest и CatQuest Voices: доступные записи звучат
из CatQuest, остальные реплики пропускаются. Проверка выполняется отдельно
для описания, промежуточной реплики и сдачи, включая восстановление очереди.
Проверка: у задания 86576 вступление должно звучать, а сдача без записи —
не попадать в очередь и не показывать голову. Недоступные старые записи
пропускаются после `/reload`; следующая доступная запись продолжает очередь.
Предпросмотр расположения в настройках остаётся отдельным демонстрационным режимом.
В TOC библиотеки перечислены только в `OptionalDeps` для порядка загрузки.
Для установки без звуков достаточно `PackageAddon`/`DeployAddon`.

Перед переходом на неизменённый внешний пак нужно решить следующие вопросы:

- Проверить загрузку в чистой Forever Beta: исходные TOC указывают Classic
  `115xx`, а наш клиент — `16001`. Сейчас доступность звука требует загруженного

- Выполнено: собственные Classic-таймеры сгенерированы по всем 10891 OGG для 4205

Генерация метаданных из внешней папки звуков и последующая проверка без записи

node tools/generate-classic-metadata.js "D:\Example\WowVoiceSounds"
node tools/generate-classic-metadata.js "D:\Example\WowVoiceSounds" --check

Генератор использует наш `Index.lua` и сами OGG; исходный аддон `WowVoice` и его

## Проверить будущее обновление CatQuest в игре

```shell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\prepare-catquest-update-test.ps1
```

Создаёт отдельный тестовый аддон в `artifacts/catquest-update-test/` без изменения
установленных файлов. Пошаговая установка, команды, ожидаемые результаты и откат:
[инструкция стенда](dev/catquest-update-lab/README.md).
Стенд имитирует новую версию, изменённые и новые записи и последующее обновление
точных измерений. В релиз он не входит.

Для проверки повтора начала после обновления установленного стенда: `/reload`,
затем `/wvcqupdate test`. Одна команда включает штатный автоматический выбор
канала, TRACE и оба тестовых трека. С фоновым звуком используется Master,
сохраняющий настройки музыки игры; без фонового звука — прежний PlayMusic,
с заглушением при сворачивании и продолжением с текущего места при возврате.
Экспериментальный `PlaySoundFile(..., "Music")` не включается.
После окончания —
`/wvcqupdate report` (до следующего `/reload`), завершение — `/wvcqupdate reset`.
