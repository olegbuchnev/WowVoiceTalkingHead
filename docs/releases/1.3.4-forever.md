## 1.3.4-forever

### Изменения

- Добавлена поддержка CatQuest и CatQuest Voices 0.7.0 — теперь библиотека содержит 4 473 описания заданий.
- Обновлены русские тексты заданий.
- Дополнены и исправлены портреты и русские имена квестодателей по актуальным данным Wowhead Forever. Уточнено определение рассказчика.
- Исправлены ракурсы детей людей и орков: головы больше не выходят за границы портрета.
- Автоматические реплики мира CatQuest по умолчанию отключаются при использовании TalkingHead Ru. Их можно включить вручную в настройках CatQuest.

---

### Changes

- Added support for CatQuest and CatQuest Voices 0.7.0, now featuring 4,473 quest descriptions.
- Updated Russian quest texts.
- Added and corrected quest giver portraits and Russian names using current Wowhead Forever data. Improved narrator identification.
- Adjusted camera framing for human and orc children to keep their heads within the portrait frame.
- CatQuest's automatic world dialogue is now disabled by default while TalkingHead Ru is enabled. It can be re-enabled manually in CatQuest settings.
