# WowVoice TalkingHead 1.2.2-forever

Очередь можно слушать подряд или по одной реплике. Обновлены данные CatQuest,
а обновление сторонней библиотеки больше не отключает всю её озвучку.

- Над очередью появилась постоянная панель: «Очистить всё»,
  «Автовоспроизведение» и «Далее». Если снять галочку, текущая реплика доиграет,
  а следующие будут ждать клика. «Далее» или ▶ у задания запускают одну реплику,
  сохраняя выключенное автовоспроизведение. Выбор галочки сохраняется.
- Удалена дублирующая кнопка «Далее» на говорящей голове. Когда звучит последняя
  реплика, очередь скрывается; ожидающая реплика остаётся доступной для запуска.
- Чекбокс «Заблокировать фреймы» управляет перемещением головы и очереди вместе.
  Изменение масштаба показывает только соответствующее окно, без разблокировки,
  с плавным исчезновением предпросмотра. Исправлены границы и выравнивание очереди.
- Поддерживаются **CatQuest Voices 0.3.0** и данные NPC **CatQuest 0.3.1**:
  обновлены тексты, файлы и точные длительности. При будущих обновлениях
  совместимые записи продолжают работать, а новые и изменённые ждут обновления
  данных WowVoice TalkingHead. Сохранённый выбор CatQuest не сбрасывается.
- Очередь остаётся видимой при скрытии интерфейса через DialogueUI.
  Исправлено размещение кнопок озвучки рядом с предметами и кнопками сворачивания
  в Questie Tracker.
- Обновлены README и скриншот очереди. Адреса картинок сайта автоматически
  меняются при замене файлов, чтобы обновлённая страница загружала новые изображения.
- Исправлено центрирование головы по горизонтали. Рамки редактирования головы
  и очереди имеют одинаковую толщину и цвет при разных масштабах и фонах.
  Опущены портреты фурболгов и женщин дворфов, чтобы оставить место над головой.
  Подняты портреты мужчин Skyborne.

## Установка и обновление

Если `WowVoiceSounds` уже установлен, достаточно **addon-only**: замените
папку `WowVoiceTalkingHead` и выполните `/reload`. **Основная звуковая база не менялась.**
Для первой установки скачайте полный архив с основной озвучкой WowVoice.

CatQuest и CatQuest Voices устанавливаются отдельно. При обновлении этих
библиотек полностью перезапустите игру, чтобы клиент загрузил новые звуки.
Настройки и очередь сохраняются по прежним правилам.
