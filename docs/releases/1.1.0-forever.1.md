# WowVoice TalkingHead 1.1.0-forever.1

- Настройки теперь открываются командой `/thead`, справка — `/thead help`.
  Остальные команды также используют `/thead`, например `/thead on` и `/thead off`.
  Команды `/wv` и `/wowvoice` освобождены для исходного WowVoice.
- Справа от заголовка настроек показаны три версии: аддона, озвучки WowVoice
  и озвучки Cathey. Названия и значения выровнены по двоеточиям.
  Версии звуковых баз соответствуют исходным пакам авторов: WowVoice — `1.0.1`,
  Cathey — `0.2.0`. Они также указаны рядом с полным архивом на сайте.
- Основные чекбоксы выровнены по началу разделительных линий в настройках.
- При импорте звуков сохраняются версия и название исходного TOC-файла,
  чтобы версии баз можно было сравнивать с выпусками авторов.
- Обновлены инструкция и GitHub Pages.

Для обновления с 1.0.8-forever.8 достаточно архива `addon-only`:
замените папку `WowVoiceTalkingHead`, выполните `/reload` и откройте `/thead`.
Записи звуковой библиотеки не изменились. Версии ранее выпущенных паков
также отображаются корректно. Для первой установки используйте полный архив.

В состав выпуска входят:

- `WowVoiceTalkingHead-1.1.0-forever.1.zip` — полный комплект со звуками;
- `WowVoiceTalkingHead-1.1.0-forever.1-addon-only.zip` — обновление аддона;
- `SHA256SUMS.txt` — контрольные суммы обоих архивов.
