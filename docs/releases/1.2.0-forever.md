# WowVoice TalkingHead 1.2.0-forever

В настройках `/thead` теперь можно выбрать WowVoice или CatQuest для заданий,
озвученных в обеих библиотеках. Выбор действует при получении и сдаче заданий,
а также при запуске из журнала и списка заданий. Если запись есть только
в одной библиотеке, используется она.

- Кнопка «Послушать озвучку» открывает каталог с фильтром по ID задания.
  Голубая кнопка запускает WowVoice, оранжевая — CatQuest. Можно сразу
  переключаться между двумя записями; прослушивание не меняет выбранный источник.
- Поддерживается прямое использование **CatQuest Voices 0.2.2**.
  Для загрузки этого пака также требуется **CatQuest**. Они устанавливаются
  отдельно; основная озвучка WowVoice работает самостоятельно.
- Без совместимого CatQuest Voices источник автоматически сбрасывается на
  WowVoice. В каталоге скрываются отсутствующая библиотека и её отдельные задания.
  При несовместимой версии в настройках показано пояснение.
- Добавлены доступные тексты и данные NPC из CatQuest 0.2.2. Они входят в сам
  аддон и помогают показывать текст и портрет при повторном прослушивании.
- Скорректировано положение ряда моделей в говорящей голове.
- Изменение масштаба панели больше не включает тестовую подсветку кнопок
  в стандартном списке заданий и Questie Tracker.
- Сайт получил встроенную тёмную тему, размеры скачиваемых архивов и описание
  выбора озвучки.

## Установка и обновление

Для первой установки скачайте полный комплект: в нём две папки —
`WowVoiceTalkingHead` и `WowVoiceSounds`.

Если `WowVoiceSounds` уже установлен, достаточно `addon-only`: замените папку
`WowVoiceTalkingHead` и выполните `/reload`. Основная звуковая база не изменилась.

Для дополнительной озвучки установите и включите **CatQuest Voices 0.2.2** и
его зависимость **CatQuest**. После установки звуков полностью перезапустите игру.

- [CatQuest на CurseForge](https://www.curseforge.com/wow/addons/catquest)
- [CatQuest Voices на CurseForge](https://www.curseforge.com/projects/1715207)

## Файлы выпуска

- `WowVoiceTalkingHead-1.2.0-forever.zip` — полный комплект с озвучкой WowVoice.
- `WowVoiceTalkingHead-1.2.0-forever-addon-only.zip` — только аддон.
- `SHA256SUMS.txt` — контрольные суммы обоих архивов.

Версия аддона теперь записывается как `1.2.0-forever`: суффикс обозначает
клиент Forever. Версии исходных звуковых библиотек указываются отдельно.
