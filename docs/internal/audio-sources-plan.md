# План: источники озвучки и три комплекта WowVoice

Статус на 28.09.2026: источники, индекс собственной базы 0.2.2, совместимость
внешнего пака, настройки, три вида сборки и шаблон сайта реализованы локально.
Проверки Lua/импорта/ZIP и сборка сайта пройдены; публикация и прослушивание
в клиенте WoW ещё не выполнялись. Ниже сохранён согласованный план.
Основание: [проверка установленного CatQuest_Voices 0.2.2](catquest-0.2.2-integration.md).
Этот план уточняет приоритеты источников: по умолчанию установленная собственная
база имеет приоритет над внешним паком независимо от их относительной свежести.

## 1. Результат для игрока

Одна версия кода WowVoice поддерживает два источника дополнительных записей:
собственный CatVoices, подготовленный из CatQuest, и установленный оригинальный
CatQuest_Voices. Источник выбирается по реально загруженным данным. Способ
установки — полный ZIP, облегчённый ZIP или ручное копирование — не задаёт режим
работы и не требует отдельной сборки Lua-кода.

| Скачивание | Содержимое ZIP | Что уже должно быть установлено |
| --- | --- | --- |
| Полный комплект | WowVoiceTalkingHead + WowVoiceSounds + CatVoices | Ничего |
| Только аддон | WowVoiceTalkingHead | Основная база и один поддерживаемый источник дополнительных записей для полного покрытия |
| Облегчённый комплект | WowVoiceTalkingHead + WowVoiceSounds | CatQuest + CatQuest_Voices поддерживаемой версии |

WowVoiceSounds остаётся основой во всех вариантах. CatQuest_Voices содержит
только часть пересекающихся с ней квестов и не содержит промежуточные диалоги `p`.
Облегчённый комплект поэтому не равен addon-only. CatVoices внутри полного
комплекта остаётся постоянно поддерживаемой базой, а не временным резервом.

## 2. Отделить каталог записей от воспроизведения

Добавить модуль `AudioSources.lua` перед `Core.lua` во все три TOC. Он описывает
каталоги, совместимость и выбор записей, но не запускает звук и не управляет UI.

Предлагаемый общий контракт:

```lua
ResolveQuestAudio(questID, section, preference)
-- record | nil, reason
-- record: path, duration, sourceID, sourceVersion, questID, section, variant
-- optional: cues

HasQuestAudio(questID) -- доступно именно описание a
EnumerateQuestIDs()   -- для локальной отладки
GetAudioSourceStatus() -- загруженные паки, версии, совместимость, причина выбора
RefreshAudioSources()  -- переобнаружение и сброс зависимых кэшей
```

Источники:

- `classic`: текущие WowVoiceDur / WowVoiceSounds, включая существующие правила
  лицензии, имён файлов, расширений и поддержку старых клиентов.
- `bundled`: новый собственный индекс CatVoices с точными длительностями.
- `catquest`: живой CatQuestVoicePack.quests + метаданные совместимости
  конкретного проверенного выпуска оригинала.
- Старый WowVoiceForeverAudio — только адаптер прежнего CatVoices 0.2.0,
  чтобы установка addon-only поверх текущего полного комплекта не ломалась.

`SoundPath` временно оставить совместимой обёрткой. Перевести `Speak`,
`ReplayQuest`, `HasQuestAudio`, локальную панель и диагностику на общий выбор.
Кнопка воспроизведения и реальный запуск должны видеть один и тот же каталог.
Записи источников и внешние глобальные таблицы не изменять.

## 3. Собственная база и подготовка совместимости

Переработать существующий импортёр в два последовательных этапа:

1. Прочитать TOC, Lua-индекс и JSON оригинального пака. Исключить целые квесты,
   уже представленные в Classic. Проверить имена, наличие файлов, структуру OGG,
   точные длительности каждого варианта, SHA-256. Восстановить проверенные
   JSON-only сдачи, в частности 99080. До конца проверки ничего не заменять.
2. Из одного нормализованного каталога сформировать собственный CatVoices
   и таблицу совместимости внешнего CatQuest_Voices. Для собственной базы копируются
   только выбранные OGG; для внешнего источника формируются только метаданные.

Собственный `CatVoices/Index.lua` загружается его TOC в отдельную глобальную
таблицу `WowVoiceCatVoicePack`. В ней: версия формата, версия исходного пака,
ревизия адаптации, записи с именами и точными длительностями. Источник версии —
реальный входной TOC. NOTICE и сведения об авторе сохраняются.
Привязка «звук + индекс» должна обновляться заменой одной папки CatVoices;
новые записи не требуют ручной правки Core.lua или нового встроенного списка ID.

Для первого выпуска целевой оригинал — 0.2.2. Ожидаемый собственный результат:
738 квестов, 1678 файлов, включая два варианта сдачи 99080. Это проверяемый
результат именно этого входного пака, а не постоянная константа импортёра.

Внешний каталог принимает только поддерживаемую версию и проверенную форму
записей; тайминги выбираются для конкретного файла и пола. Не использовать
максимальную длительность `d` вместо фактической: она уже расходится с OGG
на несколько секунд. Если запись изменена относительно проверенных метаданных
или для неё нет точного тайминга, она не считается готовой к воспроизведению.

Проверка TOC и доступных полей индекса не доказывает целостность каждого OGG
в игре. Клиент не даёт прочитать файл и пересчитать его SHA-256. Подмена OGG
при прежней версии и неизменном индексе остаётся границей обнаружения;
полная проверка выполняется внешним инструментом при подготовке выпуска.

## 4. Выбор источника при ручной установке

Предлагаемый режим по умолчанию — «Автоматически»:

1. Для квеста, у которого есть любая секция в Classic, использовать только Classic.
   Сохраняется нынешняя политика импорта; семь дополнительных сдач для Classic
   не добавлять попутно как незаявленное изменение покрытия.
2. Для дополнительных квестов сначала выбрать один загруженный и совместимый
   источник на весь каталог: если доступен наш CatVoices, использовать его.
3. Только если нашей базы нет или она недоступна, выбрать поддерживаемый
   внешний CatQuest_Voices. Неподдерживаемый формат или повреждённый индекс нашей
   базы отразить в статусе, чтобы причина использования внешнего источника была видна.
4. Отсутствие отдельного квеста или секции в выбранной базе не переключает
   источник. Не смешивать выпуски поквестно, не подменять сдачу описанием
   и не возвращать устаревшую секцию из другого пакета.

Таким образом, «Скачать полный комплект» означает использование нашей базы,
даже если рядом установлен более новый CatQuest_Voices. Обновление внешнего
пака не меняет голос, тайминги и покрытие полного комплекта. Нажатую на сайте
кнопку отслеживать не требуется: наличие нашей загруженной базы выражает тот же
приоритет при ручном копировании файлов. Установка полного комплекта поверх
облегчённого включает собственную базу при следующем обнаружении источников.

Сравнение версий не участвует в автоматическом выборе между источниками.
Версии нужны для проверки совместимости, подбора точных метаданных и отображения
в настройках. Поддержку каждого внешнего выпуска добавлять явно. `0.2.2+`
не обещается. Установка нового внешнего пакета сама по себе не делает его совместимым.

| Реальная установка | Поведение в режиме «Автоматически» |
| --- | --- |
| Основная база + новый CatVoices, без CatQuest | Все наши дополнительные записи работают самостоятельно |
| Основная база + поддерживаемый CatQuest_Voices, без CatVoices | Дополнительные записи читаются из оригинала |
| Оба пака на основе 0.2.2 | Выбирается наш CatVoices; внешняя копия не удаляется |
| Наш старый 0.2.0 + поддерживаемый внешний 0.2.2 | Выбирается наш 0.2.0; внешний используется после отключения/удаления нашего пака |
| Наш пак + более новый или более старый поддерживаемый внешний | Выбирается наш пак независимо от относительной свежести |
| Наш пак + внешний неизвестной версии | Работает наш пак; непроверенный внешний не используется |
| Только внешний неизвестной версии + основная база | Classic работает; дополнительные записи недоступны, показана причина |
| CatQuest есть, CatQuest_Voices отсутствует или не загружен | Сам CatQuest не считается источником записей; используется наш пак, если доступен |
| Нет ни одного дополнительного источника | Classic работает; одно понятное сообщение о недостающей озвучке |
| Нет WowVoiceSounds | Сообщить о неполной установке; внешний пак не выдавать за полную замену основной базы |

Источник выбирается только автоматически. Блок выбора удалён ради простоты
интерфейса; старые сохранённые предпочтения удаляются при загрузке. Вверху настроек
показывается «Озвучка CatQuest» и версия активной базы. Подробная диагностика
остаётся в `/thead diag`; `/thead source` только сообщает текущий источник.

Наличие двух каталогов — нормальный режим, не ошибка. Ничего не удалять,
не переименовывать, не выключать в списке модификаций и не править чужой TOC.
Полный комплект, установленный вручную поверх облегчённого, должен просто начать
использовать появившийся источник по этим же правилам.

## 5. Загрузка, ошибки и диагностика

Добавить OptionalDeps для CatVoices и CatQuest_Voices, без обязательной зависимости
WowVoice от CatQuest. Сохранить переобнаружение на PLAYER_LOGIN и ADDON_LOADED
заинтересованных паков. Поздняя загрузка должна обновлять кнопки журнала,
трекера, локальные подсказки ID и диагностику.

Не кэшировать глобально отсутствие источника до конца сессии. Отрицательные
результаты запуска хранить по источнику, версии, ID, секции и варианту: ошибка
в одном паке не должна блокировать исправную копию в другом. Изменение выбора
или состава загруженных источников сбрасывает соответствующие кэши.
Текущая запись сохраняет выбранные путь и тайминг до завершения; переобнаружение
не перезапускает её и не переключает транспорт посреди фразы.

Не обходить все файлы пробным проигрыванием. При реальной ошибке запуска
восстановить CVars/интерфейс, не помечать квест прослушанным и показать причину
один раз. В первом этапе не делать скрытый повтор из другого пака после
неуспешного запуска: PlayMusic не всегда надёжно сообщает о недоступном файле.
Это отдельная задача от выбора источника по каталогу.

Переписать warnIfNoSounds: отсутствие CatVoices не ошибка при доступном внешнем
источнике, отсутствие внешнего пака не ошибка для полного комплекта. Различать
отсутствие, выключенный/незагруженный аддон, неподдерживаемую версию и ошибку
воспроизведения, насколько это позволяют доступные API.

В настройках показывать реальный активный источник дополнительных записей
и версии обоих установленных паков. `/thead diag` и локальная панель объясняют
выбор конкретной записи: откуда файл, какой вариант, длительность и причина
исключения другого источника. Тип скачанного ZIP не хранится как режим работы.

## 6. Сосуществование с проигрывателем CatQuest

Чтение внешних OGG и управление CatQuest — две отдельные задачи. Даже если
выбран наш CatVoices, установленный CatQuest может автоматически читать тот же
квест. Поэтому интеграция определяется наличием активного CatQuest и включённым
WowVoice, а не выбранным источником звука.

Сохранить и проверить существующее временное подавление autoDetail,
autoProgress, autoComplete, а также скрытие кнопок чтения квестов CatQuest.
Ветка readAfterAccept уже зависит от autoDetail в проверенном 0.2.2.
Исходные значения восстанавливаются при отключении WowVoice и перед сохранением
на выходе; ручные изменения пользователя не перезаписываются безусловно.
Книги, лор и прочие функции CatQuest продолжают работать.

Гарантия первого этапа — отсутствие двух автоматических читателей квестов при
действующем подавлении. Команды ручного чтения CatQuest, его история, книги и лор
используют независимый проигрыватель; общей очереди сейчас нет. Не обещать
глобальное исключение любого наложения и не вмешиваться в приватный namespace.
Если пользователь снова включил автозапуск CatQuest, показать конфликт в
диагностике; не устраивать постоянное перетягивание его настроек.
Проверку совместимости управляющего CatQuest учитывать отдельно от версии
CatQuest_Voices: версия аудиопака не подтверждает неизменность кнопок и настроек.

## 7. Сборка, локальные команды и GitHub Pages

Заменить двоичный флаг AddonOnly внутри упаковки на явный вид комплекта:
`full`, `addon`, `lite`. Сохранить существующие публичные команды Package
и PackageAddon, добавить PackageLite. Никакая сборка одного вида не удаляет
актуальные архивы остальных видов. Содержимое WowVoiceTalkingHead одинаково
во всех трёх архивах одного релиза, локальная отладка в релизы не включается.

Предлагаемые имена:

```text
WowVoiceTalkingHead-<version>.zip
WowVoiceTalkingHead-<version>-addon-only.zip
WowVoiceTalkingHead-<version>-lite.zip
```

При реализации добавить в BUILD.local.md рабочую команду PackageLite и сценарии
локальной проверки обеих установок. Пока таргета нет, не добавлять его как
готовую запускаемую команду. DeployAddon -LocalDebug сохраняет назначение:
обновляет только код. Проверять комплекты на изолированных временных каталогах,
а включение/выключение паков и реальный звук — отдельно в клиенте.

В левой колонке Pages:

- «Скачать полный комплект · размер» — первая установка, вся озвучка включена.
- «Скачать только аддон · размер» — звуковая база уже установлена.
- «Скачать облегчённый комплект · размер» — первая установка при наличии
  CatQuest + CatQuest Voices 0.2.2; пояснить использование готовых записей
  и дать [ссылку на CurseForge](https://www.curseforge.com/wow/addons/catquest).

У каждой карточки своя версия, дата и фактический размер ZIP из GitHub asset.size;
размер должен быть заметен прямо на кнопке. Форматировать в КБ/МБ, не показывать
addon-only как «0 МБ». Данные относятся к конкретному опубликованному asset,
не к локальным исходникам и не к размеру распакованной озвучки. В третьей
карточке — точная проверенная версия внешнего пака без «+». Зеркало pCloud
расположить у полного комплекта и явно подписать его назначение.

Выбор ссылок в tools/build-site.mjs сделать явным для трёх видов: текущая
проверка «любой ZIP, кроме addon-only» ошибочно примет lite за полный комплект.
Также обновить классификацию и суммы в tools/release-stats.ps1, README,
USER_README, документацию и проверки pipeline. Публикация третьей кнопки только
после появления рабочего проверенного архива; не размещать фиктивные ссылки.

## 8. Порядок реализации и критерии готовности

1. **Нормализованный каталог и импорт.** Новый индекс собственной базы,
   адаптер старого 0.2.0, точные внешние метаданные 0.2.2, запись результатов
   только после успешной проверки исходного пака.
2. **Источники в рантайме.** Общий resolver, Classic-приоритет, таблица сценариев
   ручной установки, единый каталог для воспроизведения и кнопок. По умолчанию Auto.
3. **Совместимость и диагностика.** Загрузка в любом порядке, недоступность,
   выбранный источник, сосуществование с CatQuest и сохранение предпочтений.
4. **Три комплекта.** PackageLite, независимая очистка архивов, идентичный код
   и проверка состава ZIP; обновление BUILD.local.md после появления команды.
5. **Проверка в игре.** Новые и Classic-квесты, оба пола, описание/сдача/нет `p`,
   99080, запись 98430_f с отличающейся длительностью, повтор из трекера,
   фоновые режимы Master и PlayMusic, оба источника одновременно и поздняя загрузка.
6. **Выпуск и сайт.** Три артефакта, размер/версия/дата каждого, верная статистика,
   инструкции для первой установки и ручного смешанного комплекта.

Для кода нужны сценарии resolver в Lua-моках и проверки импортёра на fixtures:
приоритет собственной базы при любых относительных версиях, частичные секции, неизвестный внешний
выпуск, восстановление настроек CatQuest и обновление недоступности.
Полный набор проверок проекта — `build.cmd -Task Validate` и `build.cmd -Task Test`
после реализации. Моки не заменяют проверку аудио, фонового поведения и кнопок
в настоящем клиенте. Финальное условие: все три способа установки и ручная
установка обоих паков дают предсказуемый выбор без обязательной очистки папок.
