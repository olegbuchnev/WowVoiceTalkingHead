# Удаление старого снимка Wowhead Forever

Старый JSON-снимок из Forever Quest Pins (коммит
`2d354aa828af29cb2e997b7367f7bb59b75f10e2`) и его импортёр удалены из проекта.
Для Forever Quest Pins остаётся актуальный источник на основе All The Things:
`f26f006c94efce787d0f09a32462595ddac2fced`, проверен 12 октября 2026 года.

Причина: в старом снимке у задания 940 одновременно указаны NPC 3519 и
`Object #673378`. Защита от неоднозначных источников перекрывала совпадающие
данные CatQuest, Wayfarer и актуальных Pins. Теперь назначается Часовой Арания
Проблеск Солнца, облик 1543. На этот случай добавлена регрессионная проверка.

Порядок выдающих NPC: CatQuest → Wayfarer → актуальные Pins → Classic.
Защита от неоднозначных NPC в оставшихся источниках сохранена. Наблюдения
из игры по-прежнему имеют приоритет над общей базой.

| Данные | До | После |
| --- | ---: | ---: |
| NPC | 2545 | 2526 |
| Записи выдачи, включая исключения | 4681 | 4377 |
| Записи сдачи | 4288 | 4288 |
| Известные облики NPC | 2302 | 2302 |
| Сравнения на сайте | 3808 | 3808 |
| Записи озвучки на сайте | 9863 | 9863 |

Удалены 248 исключений и 56 связей выдачи, присутствовавших только в старом
снимке. Для этих 56 заданий общая база больше не угадывает NPC; в игре остаются
фактические наблюдения. В каталоге сайта портреты восстановлены у 38 заданий,
ни один ранее доступный портрет не потерян. Всего изменились сведения NPC
для 44 сравнений. Тексты, версии, хеши и состав аудио не изменились.

Обновлены генератор, тесты и скилл обновления библиотек. Старый снимок не нужен
для воспроизводимой пересборки. Он остаётся только в истории Git.

Проверено: `build.cmd -Task Test`, сверка установленного Wayfarer, регрессия
предзагрузки аудио локально и на опубликованном сайте, сравнение исходных и
облегчённых моделей (314 файлов), позы 15 эталонных/затронутых персонажей.
Бета обновлена; установленный `Speakers.lua` побайтово совпадает с исходником.

Полный автономный проход: 1348 из 1349 обликов готовы; единственное прежнее
исключение — задание 97290, display 146706, `Model has no portrait camera`.
Новые 9 обликов подготовлены успешно; полный проход заново отрисовал все модели
без обращений к внешним ресурсам. Отчёт: `artifacts/voice-vote-model-cache/verify-report.json`.

Данные сайта опубликованы существующими образами. Перенесены 60 новых файлов
кэша и обновлён манифест облегчённых моделей (архив дополнения 1 059 450 байт).
Проверены 9863 аудиохеша и 12714 зависимостей моделей на хостинге. Сохранены все
227 ранее записанных голосов, целостность SQLite подтверждена. Резервная копия:
`/srv/talkinghead/backups/20261012-remove-legacy-forever`. Аудио не переносилось.
Публичный портрет 940: `p-499bdfb5bd8d`, `ready`, ошибок загрузки нет.
