Формат индекса остался 1, модель голосов — v4. В ядре 1.0.0 сохранены

Аудит реальных файлов: 8 497 SHA-256/размеров и 15 428 проверок Lua-резолвера
с точными длительностями для обоих полов игрока.

Установленный Narrator 3.2.0 содержит пустую квестовую таблицу. Исправлен
импорт аудио: пакет без квестовых записей не создаёт пустой снимок истории
и не мешает импорту трёх квестовых модулей. Добавлена регрессия с Narrator.

При входе в игру пользователь обнаружил автоматический запуск лора зоны.
Добавлена обратимая интеграция: при включённом TalkingHead Ru временно отключаются
автозапуск квестов, книг, приветствий/сплетен и лора, автоматические уведомления,
а также всплывающие карточки и знак лора CatQuest. Ручной запуск книг/лора доступен.
`Zones.Play` блокирует ранний/отложенный автоматический лор, не меняя историю
прослушивания. При `/thead off` и выходе из игры возвращаются только значения,
которыми ещё управляет TalkingHead Ru; сторонние файлы не редактируются.

Исключение по явному выбору пользователя: повторное включение лора (`loreAuto`,
`zoneMode`) или знака CatQuest (`loreMark`) прекращает подавление этой настройки.
Маркер хранится в `TalkingHeadRuDB.libraryPreferences` и переживает `/reload`.
Само значение остаётся в базе библиотеки. При первом запуске уже включённый лор
подавляется: отличить пользовательскую настройку от значения по умолчанию нельзя.
Тесты покрывают изменения через Settings, прямые изменения, выбор уже выключенного
значения, повторную загрузку, восстановление и позднее появление библиотеки.

Общая текстовая таблица переименована из `WowVoiceQuestTexts` в
`TalkingHeadRuQuestTexts` в runtime, импортёре и тестовых данных. Сохранённые
настройки пользователя не затронуты; устаревший глобальный псевдоним не нужен.
