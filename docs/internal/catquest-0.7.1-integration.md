Общие группы `child/male` и `child/female` создавались из NPC без квестовых
ролей. Теперь реестр и список используют NPC, связанных с выдачей или сдачей
заданий. В серверном реестре 37 групп вместо 39. Все четыре группы детей людей
и орков сохранены; группы только для сдачи тоже остаются доступными.

Названия примеров предпочитают русский текст независимо от языка клиента.
Когда русского названия нет, сохраняется английское. Русское название из
журнала не заменяется; проверены enUS, enGB и ruRU.
Значки квеста, кубика и загрузки выровнены относительно центра строки.

По выбору пользователя закреплены семь портретов: Тай'джин, Травница Красивое
Перо, Люсьен Подай-Ключ, Бинк, Принцесса Мойра Бронзобород, Элаадрин Вечерняя
