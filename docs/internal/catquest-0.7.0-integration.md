## Совместимость

CatQuest 0.7.0 добавил `world=true` — автоматическую озвучку реплик NPC и мобов
из CatQuest_World. TalkingHead Ru временно отключает её по умолчанию, возвращает
исходное значение при отключении и сохраняет явный выбор пользователя через
`libraryPreferences`. Сам пакет мира не входит в квестовые индексы.
Прежние настройки подавления квестов, книг, лора и уведомлений совместимы.

Тесты обновлены по фактическим данным: новые субтитры задания 16, длительность
описания 10, русское имя Ховина Мягкоперого. Имитация будущего CatQuest теперь
использует 0.8.0, чтобы не совпадать с проверенной версией.
