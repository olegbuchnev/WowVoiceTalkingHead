## Варианты NPC

Подзаписи `npc[npcID]` содержат собственные `d/g/v/n/c`; путь записи —
`<questID>[_t]_n<npcID>[_m|_f].ogg`. Импортированы 120 дополнительных файлов
для 108 сочетаний задания, этапа и NPC. Измерения, хеши и история субтитров
хранятся отдельно. Субтитры NPC не подменяют общий текст задания.
Выбор звука использует `context.speaker.npcID`; неизвестный собеседник и
явный рассказчик используют базовую запись. Повреждённый выбранный вариант
не подменяется голосом другого NPC. Варианты пола игрока независимы от NPC.
Сайт сравнивает базовые записи описания; дополнительные NPC-варианты доступны
при обычном воспроизведении в игре.

## Forever Quest Pins

Импортирован коммит `8b8f7ca9c53f293e8cc6eead95e0f5d274ec4e98`, 5 233 задания.
Источник — QuestieDB-Forever, contractVersion 4. Семантика проверена по
[генератору базы](https://github.com/TylerAkins/forever-quest-markers/blob/8b8f7ca9c53f293e8cc6eead95e0f5d274ec4e98/internal/questdb/build.go):
`qg/qgs` происходят из `StartedBy.NPCs`, `turnIns` из `FinishedBy.NPCs`,
`turnInObjects` из `FinishedBy.Objects`. Координаты и предметы не становятся NPC.
Проверяются контракт, количества, положительные целые ID и происхождение
артефакта. Несколько NPC не сводятся к одному; объект сдачи не становится NPC.
Приоритет обеих ролей: CatQuest → Wayfarer → Pins → Classic.
Прежний ATT-формат поддерживается для исторических снимков.

Общая база: 5 144 связи выдачи, 5 063 связи сдачи, 2 668 NPC.
Существующие раса, пол и облики не изменились. Новые NPC без подтверждённых
данных оставлены неизвестными: 10993 (97930), 11051 (97937), 256388 (95819),
256391 (95816), 267806 (97065–97067). Эти задания требуют проверки в игре.
Wowhead заблокировал запрос; автоматическое дополнение остановлено, ничего
не добавлено. Отчёт: `artifacts/review/catquest-1.2.0/classification.json`.
