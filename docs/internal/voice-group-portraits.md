# Постоянные портреты групп озвучки

В таблице «Озвучка по расе и полу» используется круглая 2D-текстура,
как в плеере очереди. Представитель каждой группы закреплён в
`voice-group-portraits.json`; компактная таблица для игры —
`src/VoiceGroupPortraits.lua`. Изображения и 3D-модели в аддон не копируются.

По выбору пользователя от 18.10.2026 для `troll/female` закреплена Тай'джин
(NPC `3706`, displayID `1897`, в том числе задание `5654`, «Прикосновение слабости»).
Её представитель сохранён в JSON и остаётся прежним при следующих импортах.
Для `tauren/female` тем же решением выбрана Травница Красивое Перо
(NPC `15477`, displayID `15472`, задание `8549`, «Орде не хватает мироцвета!»).
Для `gnome/male` выбран Люсьен Подай-Ключ (NPC `2920`, displayID `4895`,
в том числе задание `734`, «Сложная задача»).
Для `gnome/female` выбрана Бинк (NPC `5144`, displayID `3108`, задание `1879`).
Для `dwarf/female` выбрана Принцесса Мойра Бронзобород (NPC `8929`,
displayID `8705`, задания `4003`/`4362`).
Для `skyborne/male` выбран Элаадрин Вечерняя Буря (NPC `252475`, displayID `138152`).
Для `scourge/male` выбран Аптекарь Лидон (NPC `2216`, displayID `1660`).

Первый выбор 17.10.2026 сделан по числу сохранённых голосов за описания заданий
NPC, суммарно по библиотекам. Учитывались только строки с текущей категорией
NPC. Повторный выбор посетителя за то же задание уже заменён в базе сайта;
личные данные в таблицу представителей не входят. При равном числе голосов
выбирается NPC с большим числом описаний заданий, затем с меньшим ID.
Для групп без голосов работает тот же резерв по заданиям. Среди кандидатов
предпочитаются NPC с известным displayID. Это выбор иллюстрации, не формула рейтинга.

`tools/generate-speakers.js` автоматически вызывает генератор портретов:

- Представитель существующей группы сохраняется при новых оценках и импортах.
- Новая группа с NPC получает представителя без ручной записи в Lua и без голосов.
- Если представитель удалён или сменил группу, выбирается замена.
- Если у группы не было известного облика, появившийся облик заменяет заглушку.
- Пустые группы не создаются; `dragon/female` сейчас отсутствует.

Для первоначального заполнения новых групп можно передать обезличенные суммы:
`node tools/generate-voice-group-portraits.js --votes=<путь-к-json>`.
Формат — массив `{npcID, race, sex, votes}`. Уже закреплённые представители
не меняются. Без файла сумм используется резерв по заданиям.
Проверка воспроизводимости: `node tools/generate-voice-group-portraits.js --check`.

Импорт строки рейтинга не меняет портреты и не требует расширения формата THR1.
Портреты заранее подготовлены и для групп без оценок, поэтому появление голосов
за драконов не требует загрузки нового изображения или отдельной обработки.
Полностью новые группы появляются после обновления общей базы NPC аддона;
группы снимка без NPC, связанных с выдачей или сдачей заданий, скрыты.
Посторонние NPC общей базы не создают категорию в списке или серверном реестре.

При открытии меню нет поиска по квестам и прогрева PlayerModel. После показа
таблицы штатный `SetPortraitTextureFromCreatureDisplayID` заполняет текстуры
через общий планировщик с бюджетом 1 мс и не более одного запроса портрета
за кадр. Нативный вызов нельзя прервать, поэтому бюджет не является жёстким
ограничением времени одного вызова. Готовая текстура переиспользуется при
перерисовке и повторном открытии; при закрытии меню оставшаяся работа отменяется.
При входе в игру работа над этими портретами не запускается.
