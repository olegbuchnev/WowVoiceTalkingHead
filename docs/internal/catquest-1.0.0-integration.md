# CatQuest 1.0.0 — 04.11.2026

## Источники и формат

CatQuest и CatQuest Voices 1.0.0 установлены в клиенте `_forever_`.
Закрытый `_classic_beta_` больше не используется для импорта или установки.
Таргет сборки — `Forever`, переменная локального конфига —
`WOWVOICE_FOREVER_ADDONS`. Старые таргет и путь отвергаются сборкой.

Форматы `ns.NpcData`, `ns.QuestGiver`, `ns.QuestFinisher`,
`CatQuestVoicePack.quests`, поля `d/g/v/n/c/t` и пути `Sounds/q` совместимы
с существующими импортёрами. Изменять импортёр CatQuest не потребовалось.
Новая настройка `bookPages` управляет продолжением ручного чтения книг;
квестовые настройки `autoDetail/autoComplete`, `world`, `loreAuto/loreMark`
сохранены. Внешний Lua разобран как данные, аудио в проект не копировалось.
