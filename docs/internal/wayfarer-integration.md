## Зависимости и поведение

Квестовые тексты импортируются отдельно командой
`node tools/import-quest-texts.js <AddOns directory>` в общую `src/QuestTexts.lua`.
Фиксированный приоритет: WowVoice → CatQuest → Wayfarer, для каждого этапа и пола
персонажа. В текущем WowVoice полных текстов нет. Карточки озвучки и прослушивание
в каталоге не меняют источник текста. Импорт CatQuest также пересобирает тексты
из соседних пакетов Wayfarer. После обновления пакетов Wayfarer нужно повторить
импорт текстов наряду с генерацией точных длительностей.

`Sources.Text(id, section)` читает общую базу независимо от загруженных библиотек
и выбранной озвучки. При отображении на ruRU приоритет имеет текст, полученный
из игры; на enUS/enGB — русский текст из общей базы. Если его нет, используется
доступный игровой текст. Эти подстановки не изменяют данные очереди и сессии.

- [x] Импорт CatQuest Lua/JSON и Wayfarer `t/tm/tf`, включая этапы `p`.
- [x] Слияние по фиксированному приоритету с заполнением отсутствующих вариантов.
- [x] Отчёт `quest-texts-manifest.json` с происхождением каждого текста.

TalkingHeadRu использует Wayfarer как третий источник рядом с WowVoice и CatQuest.
Выбор источника, резервный поиск, воспроизведение и очередь принадлежат
TalkingHeadRu. Основной Wayfarer нужен только для загрузки реестра его пакетов;
его функции поиска записей и проигрыватель адаптер не вызывает. Модель v4
выбирается первой независимо от настроек проигрывателя Wayfarer.
Нужны включённые Wayfarer и хотя бы один квестовый пакет. Полный комплект:
Wayfarer_Voices_Alliance, Wayfarer_Voices_Horde, Wayfarer_Voices_Shared.
Wayfarer_Voices_Narrator для квестовой библиотеки не нужен. WowVoiceSounds и
CatQuest_Voices остаются необязательными. Аудио читается из папок оригинала.

Пока TalkingHeadRu загружен, уведомления Wayfarer через `Util.Print` подавляются,
включая напоминания о недостающих пакетах, диагностику и отладочные сообщения.
Фильтр устанавливается до PLAYER_LOGIN и также при позднем появлении Wayfarer.
Уже выведенные при загрузке зависимости строки с префиксом `Wayfarer:` удаляются
из основного чата, если клиент поддерживает удаление сообщений. Переключатель
воспроизведения TalkingHeadRu не снимает фильтр; отключение аддона и `/reload`
возвращают обычный вывод Wayfarer. Файлы и настройки Wayfarer не меняются.

Стартовое сообщение TalkingHeadRu формируется из списка ссылок по реально
загруженным аддонам: WowVoiceSounds → WowVoice (Boosty), CatQuest_Voices →
CatQuest (https://boosty.to/cathey), Wayfarer → https://discord.gg/sgTeeQCZvh.
Незагруженные библиотеки пропускаются; без источников сообщение не выводится.
Отображаемое имя библиотеки — CatQuest, независимо от имени автора в URL.

Строка «Озвучка Wayfarer» в настройках показывает версию основного аддона из TOC,
включая установленный, но отключённый аддон. Если Wayfarer загружен, подсказка
сравнивает его версию с проверенной для адаптера 0.7.0 и версии загруженных
квестовых пакетов с `WayfarerAudio.lua`. Непроверенные версии подсвечиваются
жёлтым; подсказка перечисляет затронутые компоненты и рекомендует обновление
библиотеки либо TalkingHeadRu. Изменение только основного аддона не отменяет
точные длительности проверенных пакетов. Частичная установка поддерживается;
отсутствующие и отключённые пакеты не создают предупреждений о версии. В чат подсказка
не выводится и на приоритеты/воспроизведение не влияет.

Общая подсказка выбора озвучки кратко объясняет порядок слева направо и переход
к следующей библиотеке без символов стрелок, отсутствующих в некоторых шрифтах.
Недоступность объясняется отдельно над соответствующей карточкой при наведении,
с указанием необходимых аддонов. При частичной загрузке Wayfarer его карточка
остаётся доступной, а значок предупреждения и подсказка перечисляют недоступные
модули. Перетаскивание, закрытие и обновление доступности скрывают устаревший текст.

В настройках задаётся полный порядок трёх библиотек перетаскиванием карточек.
Захват начинается сразу при нажатии левой кнопки. Точка нажатия остаётся под
курсором с учётом масштаба интерфейса: карточка не прыгает при нажатии и начинает
следовать за мышью с первого движения, без порога начала перетаскивания.
При наведении и захвате используется встроенный курсор перемещения
`Interface/CURSOR/UI-Cursor-Move.crosshair`, как в настройках OPie. После клика
или отпускания над карточкой курсор перемещения и подсветка рамки сохраняются.
При уходе с карточки без перетаскивания, отпускании вне карточек, отмене или
закрытии настроек курсор сбрасывается. Во время перетаскивания курсор сохраняется
и за пределами карточки. Надпись неактивной библиотеки остаётся серой при захвате;
значок предупреждения справа не смещает надпись из центра карточки.
При переносе подсвечивается место назначения. Отпускание мыши над карточкой
меняет местами только исходную и целевую карточки: при переносе 1 ↔ 3 вторая
остаётся на месте. Отпускание вне ряда или закрытие настроек отменяет перенос.
По умолчанию: WowVoice → CatQuest → Wayfarer. Выбор выполняется отдельно для каждой
секции в сохранённом порядке. Например, при WowVoice → Wayfarer → CatQuest отсутствие
описания в WowVoice приводит к выбору Wayfarer, если там есть запись.
`TalkingHeadRuDB.voicePriority` хранит все три позиции. Прежний `sharedQuestVoice`
при миграции становится первым, остальные добавляются в прежнем порядке.
Недоступные библиотеки пропускаются без изменения их позиций; после включения
возвращаются на своё место. Прослушивание в каталоге и уже звучащая запись
не меняются при перестановке приоритетов.
Каталог считает только уникальные ID с описанием `a`, без дополнительных
счётчиков за `c`, `p` и варианты пола.

| Пакет | Описания `a` | Секции `a/p/c` | Файлы с учётом пола |
| --- | ---: | ---: | ---: |
| Alliance 3.1.0 | 1 245 | 2 510 | 2 619 |
| Horde 3.1.0 | 1 133 | 2 286 | 2 453 |
| Shared 3.1.0 | 980 | 1 961 | 2 224 |
| Всего | **3 358** | **6 757** | **7 296** |

Пересечений описаний между этими пакетами нет. Каталог учитывает источник каждой
записи отдельно: загруженный пакет заменяет только свой сохранённый индекс.
Записи остальных пакетов остаются видны, но кнопки сразу недоступны. Подсказка
к записи показывает имя пакета; при совпадении записи достаточно одного доступного
пакета. На карточке Wayfarer предупреждение перечисляет незагруженные или
недоступные Alliance, Horde и Shared. Ошибка загрузки, несовместимый формат или
отсутствие основного Wayfarer также не позволяют считать пакет доступным.

Для отдельного результата передать вторым аргументом корень выходных файлов:
`node tools/generate-wayfarer-metadata.js <AddOns> <output-root>`.
Генератор обрабатывает установленные из четырёх разделённых пакетов. Для обновления
общего снимка должны быть установлены все три квестовых пакета.

При несовпадении метаданных используется живая длительность + 0,25 секунды с
`verified=false`, как у CatQuest. Это оценка; точность возвращается после аудита.
WoW не читает байты OGG и не проверяет SHA-256: подмена аудио при прежней версии
и неизменных полях индекса обнаруживается только внешней проверкой.
Генератор измеряет длительность потока; правильность речи и субтитров проверяется
прослушиванием. Legacy/v3 могут работать по живому индексу формата 1, но точные
метаданные здесь подготовлены только для split v4 3.1.0.
