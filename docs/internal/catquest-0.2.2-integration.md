# Прямое подключение CatQuest_Voices 0.2.2

Исследование от 28.09.2026. Проверены установленный пак и CatQuest из
локальной папки `AddOns`, заданной в `WOWVOICE_FOREVER_BETA_ADDONS`, исходники WowVoice
и команды из `BUILD.local.md`. Здесь сохранены результаты первоначального исследования;
текущий статус реализации указан в связанном плане.

Подробный [план реализации](audio-sources-plan.md) уточняет автоматический выбор
при ручной установке обоих паков и окончательные названия трёх комплектов.

## Вывод

Использовать оригинальные OGG непосредственно из `CatQuest_Voices/Sounds/q`
можно. Перекладывать их в `CatVoices`, переименовывать или вызывать проигрыватель
CatQuest для этого не требуется. Данные для выбора файла доступны в глобальной
таблице `CatQuestVoicePack.quests`.

Рекомендуется выделить выбор аудио в отдельный модуль источников, сохранив
проигрыватель, голову, журнал, трекер и напоминания WowVoice. Однако подключение
одного Lua-индекса пока не заменяет импорт без потерь: есть зависимость от CatQuest,
нет точных длительностей отдельных вариантов и пропущена сдача одного квеста.

Сейчас WowVoice не столько «поддерживает API 0.2.0», сколько содержит отдельный
снимок его аудио: `ForeverAudio.lua` + отфильтрованная папка `CatVoices`.
Установка нового `CatQuest_Voices` этот снимок не обновляет.

## Контракт источника

`CatQuest/Core.lua:232–319` использует следующий формат:

| Секция WowVoice | Данные CatQuest | Имя файла |
| --- | --- | --- |
| `a`, описание / повтор из журнала | `quests[id]`, если есть `d` | `<id>.ogg` |
| `c`, сдача | `quests[id].t`, если есть `d` | `<id>_t.ogg` |
| `p`, промежуточный диалог | В паке нет | Не подставлять другую секцию |

Если у соответствующей записи есть `g`, перед `.ogg` добавляется `_f`
для `UnitSex("player") == 3`, иначе `_m`. Флаг проверяется отдельно у описания
и сдачи. Корень — `Interface\\AddOns\\CatQuest_Voices\\Sounds\\q\\`.

Поля: `d` — длительность; `v` — идентификатор голоса; `c.x/m/f` — текстовые
фрагменты с таймкодами; `n.x/m/f` — число букв исходного текста для QA.
**`n` не является NPC ID**, а `v` не заменяет достоверные данные о портрете.
`ForeverSpeakers.lua` и текущий механизм определения говорящего сохраняются.

Все 3664 секции Lua-индекса имеют `c`. Это возможность будущего улучшения
субтитров, но текущая прокрутка WowVoice рассчитывается по тексту и длительности
в `Portrait.lua`; одних новых путей для использования таймкодов недостаточно.

В отдельном Lua-окружении Fengari загружен настоящий `Index.lua` без кода
CatQuest. Прототип выбора разрешил все 4893 варианта; отсутствующие квесты,
секция `p` и сдача 99080 корректно остались без записи. Это проверка формата,
не воспроизведение звука в клиенте WoW.

## Ограничения, которые необходимо учесть

1. **Обязательный CatQuest.** В `CatQuest_Voices.toc:7` указано
   `## Dependencies: CatQuest`. Сам `Index.lua` не использует API CatQuest,
   но штатный загрузчик пакета требует его включения. Для первого варианта
   интеграции нужны включённые CatQuest и CatQuest_Voices. Для независимого
   пака лучше изменение TOC у автора, например OptionalDeps вместо Dependencies.
   Локальная правка чужого TOC будет теряться при обновлении.

2. **Длительности.** Для вариантов по полу `d` хранит максимум, а не длительность
   выбранного файла. Пример: `98430_f.ogg` длится 38,629833 с, индекс содержит
   42,5 с. У 615 файлов индекс превышает фактическую длительность более чем
   на 0,15 с. Есть и занижение: `132.ogg` — 21,180792 с против 21,0 с.
   Наш `PlayMusic` зацикливается и останавливается таймером; завышение может
   повторить начало, занижение — обрезать окончание. `tail` не исправит
   разницу в несколько секунд. При `PlaySoundFile` завышение сохраняет голову
   дольше аудио, занижение всё ещё способно вызвать ранний `StopSound`.

3. **Квест 99080.** Его сдача есть в JSON и двух OGG, но отсутствует в Lua.
   Прямое чтение только `CatQuestVoicePack.quests` потеряет существующее покрытие.
   Нужна небольшая проверенная таблица исключений либо исправленный индекс автора.
   Для 0.2.2 реальные длительности: 33,0935 с (`_m`) и 33,259542 с (`_f`).
   Обычный Lua-аддон не может прочитать соседний JSON как файл во время игры.

4. **Сосуществование.** В 0.2.2 сохранены `autoDetail`, `autoProgress`,
   `autoComplete`, проверка `readAfterAccept and autoDetail` и обработчики
   `CatQuest_Toggle` / `CatQuest_ReadQuestLog`. Наша текущая интеграция по коду
   по-прежнему соответствует этим точкам. Книги, лор и ручной запуск CatQuest
   остаются независимыми: общей блокировки двух проигрывателей сейчас нет.
   Работу скрытия кнопок и отсутствие двойного автозапуска нужно проверить в игре.

## Предлагаемая архитектура

Добавить `AudioSources.lua` с единым методом, например
`ResolveQuestAudio(id, section) -> { path, duration, source, cues? } | nil`.
Через него должны работать и воспроизведение, и проверка доступности.
Отдельный метод перечисления ID нужен локальной панели отладки.

Источники: Classic из `WowVoiceSounds`, внешний CatQuest_Voices и отдельный
облегчённый CatVoices как постоянно поддерживаемый вариант установки.
Существующий снимок 0.2.0 нужен только для обратной совместимости.
Данные внешнего индекса читать
при обращении; не сохранять `nil` навсегда, если пак загрузился позже.
Не изменять глобальный индекс CatQuest и не вызывать его приватный проигрыватель.

Первый этап сохраняет нынешнее правило: если хоть одна секция квеста есть
в Classic, весь квест относится к Classic. Для остальных квестов в режиме Auto
выбирается наш CatVoices, если он загружен и совместим. Внешний CatQuest_Voices
используется только при недоступности нашей базы; более новая версия внешнего
пака не меняет приоритет. Выбирается один источник дополнительных записей,
без переключения на другой при отсутствии отдельного квеста или секции.
Так полный комплект использует собственную базу и при ручной установке рядом
с CatQuest. Подробные правила и явный выбор источника описаны в плане реализации;
99080 восстанавливается метаданными.

Возможное отдельное расширение — приоритет Classic на уровне секции, а не
всего квеста. Оно добавит семь сдач: 787, 8795, 9247, 9261, 9263, 9264, 9310.
Это изменение политики покрытия, его не следует незаметно смешивать с миграцией.

Для порядка загрузки можно добавить `OptionalDeps: CatQuest_Voices, CatVoices` в три TOC
WowVoice, сохранив обработку `ADDON_LOADED` / `PLAYER_LOGIN`: обновлять кнопки,
сбрасывать кэш недоступности аудио и список ID панели после появления источника.
OptionalDeps самого WowVoice не снимает Dependencies у чужого пака.

Практический первый вариант: оригинальные OGG + живой индекс + маленькая
генерируемая таблица точных длительностей/исключений. Сканер читает исходный пак
при подготовке совместимости, но **не копирует аудио**. Таблица относится к
проверенному выпуску; старые тайминги нельзя молча применять к обновлённым файлам.
Это убирает дублирование сотен мегабайт, но пока сохраняет этап проверки метаданных.

## Три варианта скачивания на GitHub

Обязательное требование пользователя: полная установка только WowVoice должна
работать без CatQuest и CatQuest_Voices. Полный архив WowVoice содержит
WowVoiceTalkingHead, WowVoiceSounds и облегчённый CatVoices. Самостоятельность
этой установки должна сохраняться и после перехода на новую архитектуру.
Архив addon-only по-прежнему является обновлением кода для уже установленной базы.

CatVoices остаётся полноценным распространяемым паком, а не временным резервом.
Игрок выбирает один из двух способов получить
дополнительные записи:

| Установка | Что скачивать |
| --- | --- |
| Уже есть полный CatQuest_Voices | WowVoice использует его напрямую; отдельный CatVoices не нужен |
| CatQuest не установлен | Скачать полный комплект WowVoice с включённым облегчённым CatVoices; CatQuest не требуется |

Облегчённый пак содержит только квесты, отсутствующие в Classic-индексе
WowVoice, с описаниями, сдачами и вариантами по полу. Для проверенного 0.2.2
это 738 квестов, 1678 OGG и около 168,1 MiB аудио до ZIP-сжатия, включая 99080.
Это дополнение к WowVoiceSounds, а не замена основной базы.

В полном комплекте папка `CatVoices/` содержит OGG, TOC, собственный Lua-индекс
и NOTICE с указанием автора.
Версия адаптации отделена от версии исходного пака. Индекс хранит фактические
имена и точные длительности каждого файла, версию формата и исходного выпуска.
Он принадлежит паку, а не `src/ForeverAudio.lua`: замена папки аудиопака
должна приносить соответствующие метаданные без обязательного обновления WowVoice.
Для него нужна отдельная глобальная таблица, например `WowVoiceCatVoicePack`,
чтобы старый встроенный `WowVoiceForeverAudio` не перезаписал новый индекс.

Один проход импортёра проверяет оригинал и формирует как метаданные для прямого
источника, так и облегчённый пак. Аудио копируется только для второго варианта.
Полный комплект WowVoice обязательно включает этот же облегчённый пак.
Третий распространяемый архив — комплект для первой установки WowVoice
при уже установленных CatQuest и CatQuest_Voices. Внутри WowVoiceTalkingHead
(включая метаданные совместимости внешнего пака) и WowVoiceSounds, без CatVoices.
Основная база остаётся необходимой: CatQuest_Voices покрывает только часть её
квестов и не содержит промежуточную секцию `p`. Поэтому третий архив больше,
чем addon-only, но меньше полного комплекта. Отдельный архив только с
дополнительной озвучкой не является третьим вариантом на сайте.

Нужен отдельный таргет сборки `PackageLite` и команда для него
в `BUILD.local.md` после реализации. Сейчас существуют только `Package`
и `PackageAddon`; комплекта для установленного CatQuest они не создают. При добавлении третьего
типа архива необходимо изменить очистку в `Invoke-Package`: сейчас она делит
ZIP только на addon-only и остальные. Иначе сборка полного комплекта может
удалить комплект для CatQuest. Аналогично `tools/build-site.mjs` должен выбирать полный
архив явно, а не считать им любой ZIP без суффикса `-addon-only`.

В левой колонке GitHub Pages нужны три карточки, каждая с размером своего ZIP:

| Карточка / кнопка | Пояснение |
| --- | --- |
| Скачать полный комплект · размер | Для первой установки. Аддон и вся необходимая озвучка. CatQuest не требуется. |
| Скачать только аддон · размер | Только сам аддон. Для тех, у кого звуки WowVoice уже установлены. |
| Скачать облегчённый комплект · размер | Для первой установки WowVoice, если уже установлены CatQuest и CatQuest_Voices поддерживаемой версии. |

Первую карточку оставить основной визуально. В третьей дополнительно указать:
«Аддон и основная озвучка WowVoice. Дополнительные квесты — из вашего CatQuest_Voices».
Рядом явно перечислить проверенные для прямого подключения версии; для первого
выпуска планируется 0.2.2, после завершения реализации и проверки в игре.
Так пользователь не воспринимает три кнопки как три обязательных шага установки.
Зеркало pCloud подписать как зеркало полного комплекта и поместить к первой карточке.

Размер отображать рядом с кнопкой или непосредственно под ней, вместе с версией
и датой именно этого артефакта. Брать фактический размер ZIP из `asset.size`
GitHub Releases во время сборки сайта. Текущий `artifactInfo()` уже получает
метаданные нужного asset, дополнительный запрос для размера не нужен.
Использовать КБ/МБ с десятичным делителем и явно заданным округлением;
маленький addon-only не должен отображаться как «0 МБ». Размер распакованных
OGG из исследования не подставлять вместо размера скачивания.
Во всех трёх карточках показывать версию WowVoice из соответствующего выпуска.
При разных релизах размеры, даты и версии каждой карточки независимы.

В третьей карточке также указать точную поддерживаемую версию внешнего пака:
«Требуется CatQuest + CatQuest Voices 0.2.2 · [CurseForge](https://www.curseforge.com/wow/addons/catquest)».
Версию брать из метаданных совместимости опубликованного комплекта, а не из
текущей ветки разработки или номера релиза самого WowVoice. Не писать `0.2.2+`:
это необоснованно обещает поддержку будущих выпусков. Ссылка CurseForge помогает
проверить или установить необходимый для третьего варианта внешний пак.
Для первого варианта CatQuest и CatQuest_Voices не требуются.

Третья карточка появляется с рабочей ссылкой после публикации комплекта для CatQuest.
Это план выпуска: новый архив ещё не собран и на GitHub не опубликован.

Для автоматических обновлений без нашего пересчёта лучше получить от автора
полный Lua-индекс, точные длительности каждого файла и независимую загрузку пака.
Альтернатива для длительностей — переработать транспорт на естественное завершение
звука. Её надо отдельно проверить на Forever, включая сворачивание клиента:
текущий выбор PlayMusic связан с уже проверенным поведением фонового звука.
Нельзя считать замену транспорта эквивалентной только по наличию API.

## Объём следующего изменения

- `Core.lua`: вынести `foreverAudio` / `SoundPath`, перевести `HasQuestAudio`
  на общий источник, обновить диагностику и `warnIfNoSounds` (сейчас требует CatVoices).
- Три TOC: загрузить модуль источников и описать необязательный внешний пак.
- `dev/LocalDebug.lua`: учитывать ID внешнего индекса и обновлять кэш после загрузки.
- `build.ps1`, импортёр, проверки аудио: добавить комплект для первой установки
  с внешним CatQuest_Voices, сохранить полный комплект и addon-only;
  облегчённому CatVoices дать собственный индекс; убрать обязательность собственной копии там,
  где выбран внешний источник. `DeployAddon -LocalDebug` годится для установки
  такого прототипа поверх уже установленных паков.
- Инструкции установки и сайт: явно объяснить набор аддонов для каждого варианта.
- Проверки: оба пола и обе секции, отсутствующая `p`, 99080, новые ID,
  Classic-приоритет, поздняя загрузка, выключенный пак, устаревшие метаданные,
  таймер/фоновые режимы, кнопки журнала/трекера и восстановление настроек CatQuest.
  Обязателен отдельный сценарий полной установки WowVoice без CatQuest и
  CatQuest_Voices: работают дополнительные квесты, нет требований установить
  CatQuest и ложных предупреждений о недостающем внешнем паке.
  Второй обязательный сценарий: первая установка третьего комплекта поверх
  CatQuest + CatQuest_Voices, без прежнего WowVoice и без папки CatVoices.

Полностью заменять WowVoiceSounds внешним паком не рекомендуется без отдельного
решения о покрытии: Lua-индекс CatQuest содержит 1978 квестов против 4205
Classic-квестов и не содержит промежуточные диалоги `p`.

Первоначальное исследование не меняло установленные аддоны. Последующая реализация
обновила исходники и собственную базу проекта до 0.2.2; установленная игра
и опубликованные релизы не изменялись.
