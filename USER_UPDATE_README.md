# WowVoice — обновление без звуков

Это обновление самого аддона для WoW Forever Beta.
Для него нужна ранее установленная полная сборка WowVoice с озвучкой.
Звуковых файлов в этом архиве нет.

1. Распакуйте архив.
2. Скопируйте папку WowVoice в папку игры `_classic_beta_\Interface\AddOns\`,
   согласившись на объединение папок и замену файлов.
3. Если игра запущена, выполните `/reload`. Иначе запустите игру.

Существующие папки WowVoiceSounds и CatVoices оставьте на месте:
обновление использует уже установленную озвучку.
Ваши настройки сохранятся.

Для первой установки скачайте полную сборку, содержащую WowVoice,
WowVoiceSounds и CatVoices.
